# CIVIC EYE

**SEE THE ISSUE. TRIGGER THE ACTION.**

AI-powered civic issue reporting and management platform.

## Project structure
- `frontend/` — React + Vite web application
- `backend/` — Flask API, database utilities, classification module and tests

## Setup
See the frontend package scripts in `frontend/package.json` and install backend dependencies from `backend/requirements.txt`.

## Notes
Local databases, uploaded user images, virtual environments, and environment files are intentionally excluded from version control. Configure required environment variables locally before running the project.
